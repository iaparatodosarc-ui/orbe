Preguntas frecuentes

¿Es gratis?

Orbe es gratis y de código abierto. Para usarlo con Claude necesitas tu propia API key de Anthropic, que se cobra según lo que uses. Si prefieres usarlo gratis, existe Orbe Libre.

¿Qué ve Orbe de mi pantalla?

Solo envía una captura cuando tú le haces una pregunta con "Ver" activado. Puedes desactivarlo cuando quieras. Orbe no tiene servidores propios: habla directo con el proveedor de IA que elijas.

¿Dónde consigo la API key?

En console.anthropic.com → API Keys → Create Key. Pégala en Orbe la primera vez que lo abras.

¿Funciona en iPhone o Mac?

Por ahora no. Orbe está disponible para Windows, Android y Linux.
